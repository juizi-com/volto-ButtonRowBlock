# volto-ButtonRowBlock

> In juizi-blocks this block is the **Hero** block in section mode. Content built with this older block (`buttonRow`) is converted automatically when a page loads, including the preheader, title, text, background colour and image, buttons and table of contents; see [COMPATIBILITY.md](https://github.com/juizi-com/juizi-blocks/blob/main/COMPATIBILITY.md).
